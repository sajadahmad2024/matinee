# Localisation and shared widgets

`l10n.yaml` and `flutter: generate: true` come from `pubspec.md`. Generated code lands in `lib/l10n/gen/` and is committed, never edited. Every user-facing string in the app goes through `context.l10n`; the only exception is `BootstrapErrorApp`, which runs before anything is initialised.

## `lib/l10n/arb/app_en.arb`

```json
{
  "@@locale": "en",
  "appTitle": "Template",
  "homePlaceholder": "Replace this screen with the first feature.",
  "retry": "Retry",
  "goHome": "Go to home",
  "startupFailed": "The app could not start. Check your connection and try again.",
  "pageNotFound": "There is nothing at {path}.",
  "@pageNotFound": {
    "placeholders": {
      "path": { "type": "String" }
    }
  },
  "errorNetwork": "You appear to be offline. Check your connection and try again.",
  "errorCancelled": "The request was cancelled.",
  "errorAuth": "You need to sign in again.",
  "errorNotFound": "We could not find what you were looking for.",
  "errorValidation": "Some of the information provided was not accepted.",
  "errorServer": "Something went wrong on our side. Please try again later."
}
```

Adding a locale is one more `app_<locale>.arb` with every key translated, then `flutter gen-l10n`. Plurals use ICU syntax with a placeholder of `"type": "int"`.

## `lib/core/l10n/l10n.dart`

```dart
import 'package:flutter/widgets.dart';
import 'package:template/l10n/gen/app_localizations.dart';

extension AppLocalizationsX on BuildContext {
  AppLocalizations get l10n => AppLocalizations.of(this);
}
```

## `lib/core/l10n/app_exception_l10n.dart`

```dart
import 'package:template/core/error/app_exception.dart';
import 'package:template/l10n/gen/app_localizations.dart';

///
/// The one mapping from a failure to the sentence the user reads. Feature
/// screens call this instead of composing their own error text.
///
extension AppExceptionL10n on AppException {
  String localizedMessage(AppLocalizations l10n) => switch (this) {
        NetworkException() => l10n.errorNetwork,
        CancelledException() => l10n.errorCancelled,
        AuthException() => l10n.errorAuth,
        NotFoundException() => l10n.errorNotFound,
        ValidationException(:final message) => message ?? l10n.errorValidation,
        ServerException() => l10n.errorServer,
      };
}
```

## `lib/core/widgets/error_view.dart`

Used by the splash screen, the not-found screen and every feature's failure state.

```dart
import 'package:flutter/material.dart';
import 'package:template/core/l10n/l10n.dart';
import 'package:template/core/theme/app_spacing.dart';

class ErrorView extends StatelessWidget {
  const ErrorView({required this.message, required this.onRetry, super.key, this.actionLabel});

  final String message;
  final VoidCallback onRetry;

  // Defaults to the localised "Retry".
  final String? actionLabel;

  @override
  Widget build(BuildContext context) {
    return Center(
      child: Padding(
        padding: const EdgeInsets.all(AppSpacing.xlg),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          spacing: AppSpacing.lg,
          children: [
            Text(message, textAlign: TextAlign.center, style: Theme.of(context).textTheme.bodyLarge),
            FilledButton(onPressed: onRetry, child: Text(actionLabel ?? context.l10n.retry)),
          ],
        ),
      ),
    );
  }
}
```

## Directionality

Padding and alignment that differ by side use `EdgeInsetsDirectional`, `AlignmentDirectional` and `PositionedDirectional` so RTL locales lay out correctly. Icons mirror automatically; images that must mirror set `matchTextDirection: true`.
